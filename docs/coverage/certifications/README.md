# Couverture des certifications

Ce repertoire regroupe les matrices editoriales et les sources officielles de
chaque certification couverte :

- [AI-901 Microsoft Azure AI Fundamentals](ai-901.md), track actif distinct de
  l'historique AI-900, sans conversion de tentative ni credit synthetique ;
- [AZ-900 Microsoft Azure Fundamentals](az-900.md) ;
- [AZ-104 Microsoft Azure Administrator](az-104.md) ;
- [DP-900 Microsoft Azure Data Fundamentals](dp-900.md) ;
- [catalogue AWS et Google Cloud](aws-gcp-catalog.md), avec les 26 matrices du
  snapshot 2026-08-17.

Les sources de premiere partie restent detaillees dans chaque document. Les
regles communes d'identite, de provenance, de versioning et de cycle de vie
sont definies dans
[ADR-0004](../../adr/ADR-0004-multi-cloud-editorial-foundation.md).
