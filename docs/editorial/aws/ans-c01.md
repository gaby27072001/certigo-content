# Vague AWS Certified Advanced Networking - Specialty (ANS-C01)

## Perimetre

Cette vague contient 24 scenarios originaux `v3`, tous de niveau Specialty.
Chaque question publique possede une solution privee symetrique. Aucun contenu
de dump, aucune question officielle et aucune reponse ne sont recopies dans le
canal public.

| Domaine officiel | Poids | Scenarios |
| --- | ---: | ---: |
| Network Design | 30 % | 7 |
| Network Implementation | 26 % | 6 |
| Network Management and Operation | 20 % | 5 |
| Network Security, Compliance, and Governance | 24 % | 6 |

La repartition utilise l'arrondi proportionnel sur 24 elements. Les poids
officiels restent la reference exacte dans le catalogue et la matrice de
couverture.

## Cycle de vie

AWS annonce le 2026-12-31 comme dernier jour de passage de l'examen. Le
catalogue conserve donc :

- catalogue de certification : `status: active-retiring` ;
- `lastExamOn: 2026-12-31` ;
- `recommendThrough: 2026-12-31` ;
- `reviewOn: 2027-01-01`.

Le gate `isCertificationRecommendedOn` autorise la recommandation jusqu'au
2026-12-31 inclus et l'interdit des le 2027-01-01. Les questions et solutions
ne sont pas supprimees : elles restent disponibles comme corpus historique,
avec une matrice `retiring` jusqu'a la transition catalogue `retired`.
